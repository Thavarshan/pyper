# Security Policy

This repository contains educational, standard-library-only Python code (a
set of coding-challenge stubs and a solver's own test suite). It has no
runtime dependencies, does not run as a service, and does not process
untrusted input in production, so its security surface is minimal.

## Reporting a Vulnerability

If you find a genuine security issue anyway (for example, something in the
tooling/CI configuration that could be abused), please report it privately
using [GitHub's private vulnerability reporting](https://github.com/Thavarshan/pyper/security/advisories/new)
rather than opening a public issue.

Please do not report challenge-content bugs (wrong examples, ambiguous specs)
here — open a regular [issue](https://github.com/Thavarshan/pyper/issues)
for those instead.
